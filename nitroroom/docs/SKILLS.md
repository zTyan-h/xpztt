# Skills de desenvolvimento

Use skills quando forem pertinentes; valide disponibilidade nesta sessão e não presuma instalações globais no clone.

- `frontend-design` de `anthropics/skills`: obrigatória em mudanças de interface, conforme `AGENTS.md`.
- `ponytail`: solução mínima e completa.
- `orchestrate`: trabalho substancial com frentes independentes.
- `agent-skills:debugging-and-error-recovery`: falhas ou comportamento inesperado.
- `agent-skills:test-driven-development`: mudanças de lógica e regressões.
- `agent-skills:context-engineering`: contexto e instruções do projeto.
- `agent-skills:browser-testing-with-devtools`: verificação visual no navegador, quando disponível.
- `context7:context7-mcp`: documentação oficial de frameworks e bibliotecas.
- `find-skills`: descobrir uma skill quando houver uma lacuna concreta.

Não copiar skills pessoais para o repositório nem instalar dependências de agente sem necessidade.
